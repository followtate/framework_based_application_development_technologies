# Сервис управления списками литературы

## Назначение

Приложение предназначено для ведения списков литературы: добавления источников
(книг, статей, ссылок), распределения их по категориям и формирования
пользовательских списков чтения. Сервис помогает систематизировать источники,
отслеживать статус чтения и планировать изучение материалов.

# Целевая аудитория

- Студенты и преподаватели, работающие с большими объёмами литературы.
- Исследователи, ведущие тематические списки источников.
- Читатели, планирующие личное чтение и желающие вести учёт прочитанного.

# Предметная область

Управление библиографическими списками. Основные процессы: регистрация
пользователей, добавление источников, распределение источников по категориям,
формирование списков литературы и отметка статуса чтения.

# Основные сущности

- Пользователь — владелец списков (ФИО, email, логин).
- Источник — книга, статья или ссылка (название, автор, год, тип).
- Категория — тематическая группа источников (название, описание).
- Список — пользовательский перечень источников (название, владелец, статус).

# Основные функции

- Регистрация пользователя с проверкой корректности email.
- Добавление источника с указанием автора, года и типа.
- Создание категории для группировки источников.
- Создание списка литературы с привязкой к пользователю.
- Добавление источника в список с проверкой дублирования.
- Отметка статуса чтения источника (не начат / в процессе / прочитан).

# План развития

На следующих этапах планируется:

- разработка веб-приложения на Django;
- подключение базы данных и моделей предметной области;
- реализация пользователей, регистрации и авторизации;
- разработка REST API для источников, списков и категорий;
- контейнеризация приложения в Docker;
- настройка CI/CD и автотестов.
