# Сервис управления списками литературы

## Назначение

Приложение предназначено для ведения списков литературы: добавления источников
(книг, статей, ссылок), распределения их по категориям и формирования
пользовательских списков чтения. Сервис помогает систематизировать источники,
отслеживать статус чтения и планировать изучение материалов.

## Целевая аудитория

- Студенты и преподаватели, работающие с большими объёмами литературы.
- Исследователи, ведущие тематические списки источников.
- Читатели, планирующие личное чтение и желающие вести учёт прочитанного.

## Предметная область

Управление библиографическими списками. Основные процессы: регистрация
пользователей, добавление источников, распределение источников по категориям,
формирование списков литературы и отметка статуса чтения.

## Возможности

- регистрация пользователя с проверкой email и уникальности логина;
- добавление источника с указанием автора, года и типа;
- создание категории для группировки источников;
- создание списка литературы с привязкой к пользователю;
- добавление источника в список с проверкой дублирования;
- изменение статуса чтения: «не начат», «в процессе», «прочитан»;
- поиск источников по названию или автору;
- фильтрация источников по типу;
- сортировка источников по названию, автору или году;
- вывод списков литературы и их содержимого;
- сохранение и загрузка данных в JSON;
- обработка некорректного ввода и ошибок файлов.

## Архитектура

Проект разделён на модули:

- `main.py` — консольное меню и вывод данных;
- `users.py` — регистрация и поиск пользователей;
- `sources.py` — работа с источниками;
- `categories.py` — работа с категориями;
- `lists.py` — работа со списками литературы;
- `storage.py` — чтение и запись JSON;
- `utils.py` — безопасный ввод и вспомогательные функции;
- `data/` — JSON-файлы данных;
- `tests/` — автоматизированные тесты pytest.

Классы и объекты на этом этапе не используются: данные представлены словарями
и списками, поведение — функциями. Это соответствует требованиям ПР2.

## Формат данных

`data/users.json` — словарь пользователей, ключ — логин:

```json
{
  "ivan": {
    "full_name": "Иван Иванов",
    "email": "ivan@example.com",
    "login": "ivan",
    "registered_at": "2026-10-19T12:00:00"
  }
}
```
